📱 Top Mobile Games Webpage

📌 Project Description

This project is a simple and attractive HTML-based webpage that displays the Top 10 mobile games in the world.
Each game is shown in a numbered list (1–10) along with its image and basic information.
A background image is added to enhance the visual appearance of the webpage.

This project is suitable for:
College assignments
HTML & CSS practice
Beginner web development learning

🛠️ Technologies Used

HTML5 – for webpage structure

CSS3 – for styling and layout

Images – for game visuals and background

📂 Project Structure
TopGames/
├── index.html
├── style.css
├── ABSTRACT_WALLPAPER_Mesa_de_trabajo_1.jpg
└── README.md

🎮 Features

Displays Top 10 Mobile Games in list format

Each game includes:

Game image

Game name

Short description

Attractive background image

Clean and readable design

Beginner-friendly code

▶️ How to Run the Project

Download or copy all project files

Make sure all files are in the same folder

Open index.html using any web browser (Chrome, Edge, Firefox)

The webpage will load automatically
